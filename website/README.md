# Prady Official Website & Playground

Official documentation, web playground, and binary download portal for the [Prady Programming Language](https://github.com/technopradyumn/prady).

## 🚀 Features

- **Interactive Playground**: In-browser parser, token inspector, AST viewer, and execution engine for `.pr` code.
- **Cross-Platform Download Hub**: Windows (x64), macOS (Intel & Apple Silicon), and Linux (x64 & ARM64) downloads powered by `latest.json`.
- **Language Documentation**: Syntax guide, architecture validation rules, and quick-start tutorials.

## 🛠️ Local Development

Open `index.html` in any modern web browser or serve it with any static HTTP server:

```bash
# Using Python
python -m http.server 3000

# Using Node / npx
npx serve .
```

## 🌐 Deployment

Configured for automatic zero-configuration deployment on **Vercel** (`vercel.json` included).
Pushing to the `main` branch deploys automatically.
