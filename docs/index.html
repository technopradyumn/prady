        Cross-Platform Toolchain
        
How to Install & Run Prady on Any Device

        
Prady provides a native CLI toolchain (`prady`) that can be installed on Windows, macOS, or Linux in minutes.

      


      
      

        
        
        
      


      
      

        

          
1

          

            
Install Prady Globally with One Command

            
If you have Rust and Cargo installed, run this anywhere in PowerShell or Command Prompt:

            

              cargo install --git https://github.com/technopradyumn/prady prady-cli
              
            

            

              Or if you have the repository cloned locally on your laptop:
            

            

              cargo install --path compiler/prady-cli --force
              
            

          

        


        

          
2

          

            
Verify Environment with prady doctor

            
Open any terminal and confirm the compiler diagnostic doctor is active:

            

              prady doctor

1. Getting Started with Prady

          

            Prady source files end with the .pr extension. Every executable program begins execution at fn main():
          

          

            // main.pr
fn main() {
    print("Hello from Prady!");
}
          

          
Run your file with: prady run main.pr

        


        

          
2. Variables & Mutability

          
In Prady, all variables are immutable by default. If you intend to reassign or mutate a variable, you must explicitly declare it with mut:

          

            let x: Int = 10;       // Immutable variable
let mut counter = 0;   // Mutable variable
counter += 1;          // Valid
// x = 20;             // Compile-time error: cannot reassign immutable

4. Functions & Returns

          
Functions are declared with fn, typed parameters, and an explicit return type via ->:

          

            fn multiply(a: Int, b: Int) -> Int {
    return a * b;
}
          

        


        

          
5. Architecture as Code

          
Prady allows software teams to declare architectural policies right inside the code. The compiler enforces that layer boundaries are strictly observed:

          

            architecture backend {
    layer presentation;
    layer application;
    layer domain;
    layer infrastructure;

    presentation -> application;
    application -> domain;
    infrastructure -> domain;

    domain cannot import presentation;
    domain cannot import infrastructure;
}
          

        


        

          
6. OOP, Structs & Interfaces

          
Prady champions composition over inheritance through interfaces and classes:

          

            interface PaymentGateway {
    fn charge(amount: Int) -> Bool;
}

class CheckoutService {
    gateway: PaymentGateway;

    fn new(gateway: PaymentGateway) -> CheckoutService {
        return CheckoutService { gateway };
    }
}

        Release Engineering
        
Version History & Engineering Roadmap

        
Prady follows strict semantic versioning and comprehensive engineering gates.

      


      
      

        

          
v0.1.0 (Current Stable)

          Released: September 2026
        

        
Phase 1: Foundations & Front-End Core

        
Initial release establishing complete compiler front-end, diagnostics, tooling, and developer ecosystem.

        
    
          
  • ✓ Lexer Engine: Full tokenization with precise line/column spans, numbers, strings, comments, and keywords.
    • 
          
  • ✓ Pratt Parser: Operator precedence expressions, statements, functions, classes, and architecture blocks.
    • 
          
  • ✓ AST & Visitor: Strongly typed Abstract Syntax Tree with complete AST printer.
    • 
          
  • ✓ Diagnostic Bag: Rust-style ANSI diagnostics with colored headers, code spans, caret pointers, and notes.
    • 
          
  • ✓ Prady CLI: Cross-platform executable supporting check, ast, tokens, run, new, doctor.
    • 
          
  • ✓ VS Code Support: Extension with TextMate syntax highlighting, Code Runner, and problem matchers.
    • 
          
  • ✓ Live Browser Studio: Interactive in-browser compiler, AST viewer, token inspector, and sharing.
    • 
        

      


      
      

        

          
v0.2.0

          

            
Phase 2: Name Resolution & Semantic Core

            
Symbol tables, lexical scopes, primitive type checking (Int8..64, Float32..64, String, Bool), function signature validation, and tree-walking evaluator.

          

        


        

          
v0.3.0

          

            
Phase 3: Native Backend & LLVM Codegen

            
LLVM IR generation from Prady IR, O0-O3 optimization passes, platform linker integration (lld / MSVC), and standalone native executable generation.

          

        


        

          
v0.4.0

          

            
Phase 4: Pattern Matching, Generics & Monads

            
Algebraic data types (enum with payloads), exhaustive match expressions, generic type parameters, and the ? error propagation operator.

          

        


        

          
v0.5.0

          

            
Phase 5: Complete DSA Standard Library

            
28 production-grade data structures (Heaps, Trees, Graphs, LRU Cache) and full algorithmic suites with documented Big-O time and space complexity.

          

        


        

          
v0.6.0

          

            
Phase 6: OOP & SOLID Quality Engine

            
Compile-time SOLID heuristic analyzers (SRP, OCP, LSP, ISP, DIP), cyclomatic complexity limits, and automated architecture policy enforcement.

          

        


        

          
v1.0.0

          

            
Phase 10: General Availability (GA)

            
Enterprise production grade, package manager registry (prady add), language server protocol (LSP), and debugger integration.
